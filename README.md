# Торренты TV для Lampa

Плагин для [Lampa](https://github.com/yumata/lampa-source), который делает просмотр торрентов на телевизоре удобным с пульта.

## Установка

Lampa → Настройки → Расширения → «Добавить плагин» → адрес:

```
https://bregal1337.github.io/tv.js
```

Файл публикуется через GitHub Pages (репозиторий [bregal1337.github.io](https://github.com/Bregal1337/bregal1337.github.io)): после обновления новая версия доступна через несколько минут, Lampa подхватит её при следующем запуске.

Нужны настроенные в Lampa парсер (JacRed или Jackett) и TorrServer.

## Что умеет

**Экран сериала** (открывается кнопкой «Торренты» на карточке)
- сезоны с постерами, числом раздач и прогрессом просмотра;
- серии с кадрами из TMDB, длительностью, датой выхода и отметками «✓» / «▶ 23:15»;
- «▶ Продолжить с …» и «С начала»; при открытии фокус сразу на серии, где вы остановились;
- выбор озвучки и качества — плагин сам подбирает лучшую раздачу сезона, её можно сменить;
- OK на серии сразу запускает её: плагин находит нужный файл в TorrServer, плеер получает плейлист следующих серий;
- долгое OK — «С начала», «Отметить просмотренной», «Выбрать файл вручную».

**Экран фильма** — описание, выбор озвучки, качества и раздачи, «Смотреть» / «Продолжить».

**Список раздач** («Все раздачи»)
- быстрые фильтры кнопками с числом раздач: качество, тип перевода, студия озвучки, сезон, источник, трекер, HDR/DV;
- студии и дорожки берутся из реальных звуковых дорожек (ffprobe из JacRed), а не только из названия;
- умная сортировка, «★ Лучший вариант», скрытие экранок, битрейт, 5.1/7.1, русские субтитры.

**Список файлов TorrServer** — серии плиткой с крупными кадрами.

**Несколько источников** — к парсеру Lampa можно добавить свои Jackett/JacRed (Настройки → «Торренты TV» → «Дополнительные источники», формат `адрес|ключ`, через запятую). Запросы идут параллельно, одинаковые раздачи склеиваются, у раздачи видно, откуда она пришла (⊕), неответивший источник не мешает остальным. Поиск rutor через TorrServer тоже подключается, но на ТВ с 2 ГБ не нужен: TorrServer с ним занимает +300–400 МБ.

**Досмотренные серии после внешнего плеера** — MX сам идёт по плейлисту и возвращает в Lampa позицию только последней серии, а если Android выгрузил Lampa посреди просмотра — ничего. TorrServer же помнит каждый файл, который открывал плеер. При запуске плагин запоминает, какой файл какая серия, а при следующем старте Lampa (и при возврате из плеера) спрашивает TorrServer, до какой серии дошёл плеер: все серии до неё отмечаются просмотренными, «Продолжить» встаёт на неё. Позицию внутри последней серии восстановить нельзя — её знает только плеер.

**Аниме с сезонами одним списком** — TMDB часто держит все части одним сезоном («Магическая битва»: 1 сезон, 59 серий), а на трекерах это «1 сезон» (24), «2 сезон» / «ТВ-2» (23), «3 сезон» (12). Если раздачи знают сезоны, которых нет в TMDB, плагин делит сезон TMDB по длинным перерывам между датами выхода серий и показывает сезоны как на трекерах. Файлы в раздачах тоже сопоставляются: без сезона в имени («Jujutsu Kaisen - 05» в раздаче «2 сезон»), S02E05, папки [TV-1]/[TV-2] и сквозная нумерация 1–59 — прогресс пишется своей серии, в плеер уходят правильные названия.

**Удалить из истории** — долгое OK на карточке (в «Истории», на главной, в поиске) или кнопка «Закладки» на странице фильма → «Удалить из истории». Фильм или сериал пропадает из «Истории» и «Продолжить», прогресс всех серий сбрасывается, плагин забывает последнюю серию; закладки и выбранная озвучка остаются. С синхронизацией удаление уходит на остальные устройства человека. Обычная галочка «История» в том же меню убирает карточку только из списка, а прогресс оставляет.

**Телефон** — в портретной ориентации экран сериала идёт одной лентой: сезоны, кнопки с озвучкой и качеством, список серий. Первое касание серии выбирает её, второе — запускает.

## Синхронизация между устройствами (GitHub)

Переносит между телевизорами и телефоном одного человека: прогресс серий и фильмов, отметки «просмотрено», все закладки Lampa (Закладки, Нравится, Позже, История, Смотрю и т. д.), выбранные озвучку, качество, раздачу и последнюю серию.

Всё хранится в одном приватном репозитории: папка на человека, в ней файл на устройство. Устройство пишет только свой файл, читает все и берёт самое свежее, поэтому ТВ и телефон не затирают друг друга, а удалённые закладки не возвращаются.

**Один раз создать репозиторий и токен** (на телефоне или компьютере):

1. github.com/new → имя `lampa-sync` → **Private** → Create repository.
2. github.com/settings/personal-access-tokens/new (Fine-grained token):
   - Token name: `lampa-sync`, срок действия — максимальный;
   - Repository access: **Only select repositories** → `lampa-sync`;
   - Permissions → Repository permissions → **Contents: Read and write**;
   - Generate token → скопировать (`github_pat_…`).

**На каждом устройстве:** Настройки → «Торренты TV» → «Синхронизация через GitHub»:

- **Чей это телевизор** — имя человека латиницей, например `ya`. На всех устройствах одного человека — одинаковое, у других людей — своё (`mama`, `dacha`…);
- **Репозиторий** — `lampa-sync`;
- **Токен GitHub** — нажмите, откроется системная клавиатура Android (даже если в Lampa выбрана своя). На телефоне в приложении Google TV в режиме пульта нажмите значок клавиатуры и вставьте скопированный токен, затем «Готово». На экране от токена видны только последние 4 символа;
- «Синхронизировать сейчас» — внизу появится время и результат.

Дальше всё само: изменения с других устройств забираются при запуске Lampa, при возврате из плеера и раз в 10 минут. Свои изменения копятся и уходят одним коммитом не чаще раза в 10 минут — и сразу, когда вы уходите из Lampa (в плеер или выходите) или нажимаете «Синхронизировать сейчас». Если ничего не поменялось, коммита нет. В файле — только прогресс, отметки и короткие карточки закладок (название, постер, год, оценка): описание Lampa загрузит сама, когда карточку откроют.

Имя задаётся один раз на новом устройстве: если сменить его на телевизоре, где уже есть история, эта история уйдёт в папку нового имени. Все устройства с этим токеном технически могут читать все папки репозитория — для семьи это нормально. Токен хранится в Lampa на устройстве, на экране показываются только последние 4 символа. Когда срок токена закончится, создайте новый и вставьте его на устройствах.

## Настройки

Lampa → Настройки → «Торренты TV»: новый экран торрентов, экран фильма/сериала, предпочитаемое качество, запоминание фильтров, плитка серий, сброс любимых озвучек.

## Про запоминание момента

Прогресс хранится средствами Lampa (Timeline) и привязан к карточке, сезону и серии, поэтому не зависит от выбранной раздачи. Внешний плеер (MX Player, VLC) возвращает позицию в Lampa после закрытия. Если Android выгрузил Lampa из памяти во время просмотра, позиция серии теряется, но номер последней запущенной серии плагин помнит сам.
